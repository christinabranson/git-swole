WHAT THE BIG SCREEN ADDS
The rail keeps all six screens one click away, and a selector strip under the header switches between whatever the screen is a list of — exercises, sessions, lifts, program days. Nothing is behind a back button.
The session screen is one set at a time: the current set at arm's-length size with plate math and a loaded-bar diagram, a stepper for reps, and one button to log it. Rest replaces that block and the queue stays put.
Under it the whole session sits in one table: one row per exercise, warm-up and working sets as columns. Logging walks the ramp then the working sets in order, across exercises, and any cell can be clicked out of order.
The program editor is the payoff for a keyboard. Every field is an input, mode tags cycle on click, rows delete inline.
